# Reel Campaign Brief: "Nidhi Masala is Live Online!"

A production-ready brief for an AI video agent or creative director.  
Customised for **Nidhi Masala (Nidhi Grah Udyog)** — the NGU full-stack spice e-commerce storefront.

**Reference look:** `instagram-reel-reference.jpg` in this folder  
(host talking to camera + large phone UI overlay + finger pointing at the key action + big captions).

---

## 1. Video Overview

| Field | Detail |
|-------|--------|
| **Campaign** | Online store launch — “We’re live across India” |
| **Brand** | **Nidhi Masala** (legal: Nidhi Grah Udyog) |
| **Product** | Authentic Indian spices & masalas — pure blends, hand-packed in Barnagar |
| **Platform** | Mobile-first **website** (not a native app). Show a phone browser UI of the live storefront. |
| **Live URL** | `https://nidhigrahudyog.com` |
| **Goal** | 1) Announce the online store 2) Show how easy ordering is 3) Highlight real storefront features 4) Cover online-only payment (No COD), shipping, returns & support honestly |
| **Format** | Vertical Instagram/YouTube Shorts Reel — **9:16** |
| **Length** | ~60 seconds (4 scenes) |
| **Tone** | Warm, energetic, kitchen-table friendly — “family spice brand that finally went digital” |
| **Presenter** | Young adult host, smart-casual (mustard / warm spice tones ok), talks to camera, points at a large 2D phone overlay |
| **Language** | Primary script in **English** with light Hinglish energy optional on captions; store itself supports EN / HI / Hinglish / GU / MR / PA |

> ⚠️ **IMPORTANT PAYMENT POLICY:** **Cash on Delivery (COD) is NOT available.** Nidhi Masala operates on a **100% online prepaid model**. Orders are dispatched upon payment confirmation via Razorpay (UPI, Google Pay, PhonePe, Paytm, Cards, Netbanking, Wallets). The video presenter and UI overlays MUST explicitly depict online payments and clarify **No COD**.

**Visual**
- Host in a bright Indian home kitchen / warm studio (turmeric gold, saffron, rust red palette).
- Large flat **2D phone** (~25–30% of frame) pops in beside them — style matches `instagram-reel-reference.jpg`.
- Phone shows the **Nidhi Masala homepage** (hero: “Taste of Tradition in Every Spice”, spice product tiles, trust ribbon).

**Host script**

> **50+ blends. 1.1 million kitchens already trust us.** Now shop anytime at **nidhigrahudyog.com**!”

## 6. Production Notes for AI Video Agent

### Visual style (match the reference image)
- **9:16 vertical**, Instagram Reel chrome optional (hearts/comments UI is fine for mock style, not required).
- Host left / center-left; **oversized phone mockup** right (~25–35% of frame).
- Finger pointing at the primary CTA on the phone (e.g. Add to Cart / Pay / Shop Now).
- Bright living-room or modern kitchen bokeh background — warm, inviting, not corporate grey.
- Colour palette: **saffron, turmeric gold, chilli red, cream, deep brown** (align with storefront primary/accent).

### Phone UI fidelity
- Prefer **real screenshots** from `https://nidhigrahudyog.com` (home, products, cart, checkout, my orders, assistant widget).
- If generating UI, mimic a clean mobile e-commerce site branded **Nidhi Masala**, not a generic “ContentHub” demo.
- Show **₹** pricing, Indian payment icons (UPI, cards, netbanking, wallets — **strictly NO Cash on Delivery / COD**), and spice product photography.

### Accuracy guardrails (critical)
| ❌ Do not say / show | ✅ Say / show instead |
|----------------------|-----------------------|
| “Download the app” | “Open nidhigrahudyog.com” / “Shop on our website” |
| “Cash on Delivery available” / “Pay on Delivery” | “100% Secure Online Payment (UPI, Cards, Netbanking)” / “No COD available — prepaid dispatch” |
